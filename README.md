# 🧮 CalcByAdil – Modern Calculator

A modern, stylish, and responsive web-based calculator built using HTML, CSS, and JavaScript. It provides a clean user interface with a digital LCD-style display and smooth interactive buttons for performing basic mathematical calculations.

## ✨ Features

- 🎨 Modern dark-themed UI
- 🖥️ Digital LCD-style display
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- ⌫ Backspace functionality
- 🔄 All Clear (AC) button
- ⌨️ Keyboard support
- 📱 Responsive design
- 🔢 Automatic number formatting
- ⚡ Smooth button animations
- 🚨 Error handling for division by zero

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling, gradients, animations, and responsive design
- **JavaScript** – Calculator functionality and DOM manipulation
- **Google Fonts** – IBM Plex Mono and Manrope

## 🧠 How It Works

The calculator uses JavaScript functions to handle user input and perform mathematical operations.

- `inputNum()` – Handles number input.
- `inputDot()` – Handles decimal input.
- `chooseOp()` – Selects mathematical operators.
- `evaluate()` – Calculates the final result.
- `clearAll()` – Resets the calculator.
- `backspace()` – Removes the last entered digit.
- `percent()` – Calculates percentage.
